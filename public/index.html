CF AI Gateway Tracker

Unified AI usage tracking through Cloudflare AI Gateway. One applet to rule them all.

What it does

📊

Unified Analytics

Track Xiaomi MiMo, OpenAI, Anthropic, Grok, Workers AI, and any BYOK provider in one dashboard.

💰

Cost Tracking

Real-time USD costs across all providers. Budget alerts and run-out date estimation.

⚡

Omarchy Panel

Native integration with the Omarchy agents panel. Daily/monthly meters, 7-day charts, per-model breakdowns.

🔒

BYOK Support

Bring your own keys for any provider. Cloudflare routes and tracks everything.

Xiaomi MiMo OpenAI Anthropic Google Gemini Grok Workers AI Mistral Replicate AWS Bedrock Azure OpenAI + 20 more

Quick Start

# Clone and setup
git clone https://github.com/hansakoch/cf-ai-gateway-tracker.git
cd cf-ai-gateway-tracker
./setup.sh

# Configure
nano ~/.config/cf-ai-gateway/config.json

# Test
python3 ~/.local/bin/cf-ai-gateway-collector --test

Route Your Traffic

Change your base URL to route through CF Gateway:

# Before
https://token-plan-sgp.xiaomimimo.com/v1

# After
https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/xiaomi/v1
